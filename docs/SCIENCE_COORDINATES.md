# Scientific coordinate contract

The native cube has dimensions [row, column, wavelength]. Pixel centres are
one-based: x is column and y is row. No transpose or display rotation enters a
measurement. The canonical mathematical image plane has +x to the right and
+y upward; its x,y basis is right-handed. A screen with row increasing downward
has opposite visual handedness, which does not change the stored coordinates.

An axial image angle, pa_image_deg, is measured from +y toward +x, modulo
180 degrees: vertical is 0 degrees, horizontal is 90 degrees. Positive angles
are clockwise in the canonical y-up drawing. Eigenvector signs are not
receding-velocity directions. All structural component, bar and ring results
use this convention. Axis ratios mean minor/major (b/a); ellipticity is 1-b/a.

pa_sky_deg is east of north in the celestial tangent plane. It must be derived
from a WCS transformation, never copied from pa_image_deg. The internal
conversion accepts an explicit pixel-to-sky function so parity, rotation and
the local sky metric are determined by the caller's WCS. Missing WCS means
missing sky PA, not an assumed north-up frame.

phi_bar_disc_deg is an axial angle in the disc plane relative to the disc major
axis. With the NIRVANA convention, X = dx*sin(PA)+dy*cos(PA),
Y = dy*sin(PA)-dx*cos(PA), Yd = Y/cos(inclination), and theta = atan2(-Yd,X).
The bar angle uses precisely this theta. The legacy deprojection has a
different sign convention and is explicitly identified, not silently mixed.

Display transforms apply to image, mask, centre and axis endpoints together.
Angles remain in the native frame; an on-screen arrow is generated by
transforming its endpoints. A 90-degree input rotation changes the native
image angle by 90 degrees modulo 180 and rotates the measured mask.

Historical input pa_deg is accepted only as a warned alias for image PA;
bar_phi_deg and phi_b_deg are warned aliases for the in-plane bar angle.
New result fields do not reuse those ambiguous names. Saved pre-0.4 objects
must be explicitly migrated or recomputed; they must not be reinterpreted by
renaming a sky angle or an old catalogue angle without conversion.
