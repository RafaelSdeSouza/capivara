# Paper Reproduction

The published paper is **de Souza et al. (2025), “capivara: a
spectral-based segmentation method for IFU data cubes”, MNRAS 539,
3166–3179**, DOI
[10.1093/mnras/staf688](https://doi.org/10.1093/mnras/staf688), arXiv
[2410.21962](https://arxiv.org/abs/2410.21962).

## Status

The repository contains the available real-data panels and research
scripts. The original 2025 figure pipeline is not yet available as a
single reproducible command. The
[Examples](https://rafaelsdesouza.com.br/capivara/articles/examples.md)
page shows the current MaNGA results.

## Citation

Use the package citation:

``` r
citation("capivara")
```
