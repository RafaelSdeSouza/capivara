# List the installed kinematic model modules

Capivara keeps emission-line measurements and kinematic segmentation
independent from dynamical interpretation. A model module is selected
only after the velocity maps have been made. The axisymmetric disc is
the neutral comparison model; a bisymmetric bar is an explicit
additional hypothesis.

## Usage

``` r
kinematic_models()
```

## Value

A data frame describing the available model modules.
