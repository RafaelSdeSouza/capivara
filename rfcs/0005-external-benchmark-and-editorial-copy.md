# RFC 0005 — External benchmark, design direction and editorial samples

**Status:** independent design/editorial audit (20 November 2026); not a website rebuild or methods validation.  
**Scope:** current published CAPIVARA homepage and source-backed docs versus documented conventions of leading scientific software.  
**Design goal:** outstanding scientific communication, not a template copy or aspirational branding.  
**Research boundary:** established results belong in stable docs; mathematical speculation belongs in a clearly marked *Research* section.

## A. What is actually benchmarked?

| Package | Public evidence | What it does especially well | Specific CAPIVARA adaptation |
|---|---|---|---|
| [Astropy](https://docs.astropy.org/en/stable/) | Getting Started, User Guide, Learn, API, coordinated-package references | Separate introductory learning, physical measurement conventions, discoverable exhaustive references | Scientific measurement/data-contract guide at the centre of the platform; separate tutorials, user guide, mathematical definitions and API |
| [Photutils](https://docs.astropy.org/projects/photutils/en/stable/) | Task-indexed guide, clear support/segmentation concepts, worked examples | Moves from an astronomical measurement problem to a precise implemented tool | A real MaNGA question on every example page, with result, image, limited methods and provenance |
| [Specutils](https://docs.astropy.org/projects/specutils/en/stable/) | Spectrum object for multidimensional arrays, quantities, uncertainty, masks, WCS, loaders | Data representation follows astronomical physical quantities | Astropy/specutils adapters rather than duplicate/silent WCS or unit rules; validate flux density and measurement uncertainty |
| [SunPy](https://docs.sunpy.org/en/stable/) | Tutorials, how-to guides, example gallery, topic guides, reference | “How?” and “why?” are distinct user needs | New *Questions* and *Methods* sections: every method has a scientific explanation and an executable example |
| [S2FFT](https://astro-informatics.github.io/s2fft/) and [S2WAV](https://astro-informatics.github.io/s2wav/) | Algorithms, sampling theorems, mathematics, differentiable implementations, diagrams, benchmarks | Theory is visible in computational demonstrations, with clearly named limitations | Mathematical plates linked directly to correctness tests, counterexamples, and genuinely new hypotheses; animations show a property rather than decorative effects |
| [scikit-learn example gallery](https://scikit-learn.org/stable/auto_examples/) | Reproducible figures grouped by purpose | A visual index leads directly to runnable examples, with code and interpretation | A gallery of real MaNGA/MUSE analyses and carefully labelled simulations; labels linked to region spectra, criteria and QC |

These packages are benchmarks for **documentation structure and scientific implementation**, not automatically for “most citations,” visual aesthetics, or CAPIVARA's scientific aims. The work needs separate citation/usage evidence before making a ranking claim.

### Current CAPIVARA website, inspected

- The [homepage](https://rafaelsdesouza.com.br/capivara/) appropriately links the MNRAS paper, provides a genuine MaNGA mosaic, an installation command and an executable synthetic example. Retain all of this content.
- The synthetic quickstart is currently too prominent as homepage content; prefer a 15–25-line minimum example, with the full generative script in its own reproducible article.
- The [reference index](https://rafaelsdesouza.com.br/capivara/reference/index.html) already groups functions by scientific task, but autogenerated titles such as “Cluster a 2D Representation of a Data Cube” explain mechanics more readily than scientific motivation.
- The R source has more advanced wavelength/LSF, support, representation and spatial-convention contracts than are apparent in the earlier indexed public site. The live site must be *rebuilt from the current validated R source* and deep links preserved—never claimed complete from an older cached view.
- The prior HTML prototypes use a visually oversized opening headline and place the strongest data panel below the fold. Their simulated galaxies demonstrate interface interactions but cannot serve as definitive proof of scientific utility.
- Neither the current published site nor the HTML mock provides an actual new spectro-spatial operator, and the proposed mathematical section must never suggest otherwise.

## B. Final recommended visual hierarchy

**The scientific data should be seen immediately, not after a screen of oversized headline copy.** Keep one underlying system for both light editorial documentation and dark visualization plates.

### Page 1: Scientific homepage — “One galaxy. Several spectral questions.”

**Desktop layout (12-column grid, adaptive mobile):**

```text
 CAPIVARA         Guide | Examples | Mathematics | Reference | R / Python
 -------------------------------------------------------------------------
   SHORT TEXT (4 columns)        REAL SCIENCE FIGURE (8 columns)
   One galaxy.                   Original MaNGA map
   Several spectral questions.   + CAPIVARA segmentation
   2 natural sentences           + linked regional spectra
   Start / See the analysis      + label/caption and data provenance
 -------------------------------------------------------------------------
   Choose what you compare  /  Set the spatial support /  Check the regions
 -------------------------------------------------------------------------
   Two examples of science-first work, one uncertainty/failure demonstration
 -------------------------------------------------------------------------
   Explicit: R available / Python under development / cite the paper
```

The primary figure occupies **more visual area than the words**. It has **one** central scientific message, consistent colors across regions/spectra, line identities and units. Never label a synthetic demo as a result of running published CAPIVARA on MaNGA. Use the **existing genuine MaNGA mosaic** while a genuinely matched cube+segmentation+spectra figure is prepared.

### Page 2: Method — “What does spectral similarity mean?”

A visual comparison, not a wall of function options: **same galaxy** → full-flux vs spectral-shape vs line-profile representation → different valid comparison and retained information. Below it, a small equation, use cases, important failure and actual code in R/Python (only validated paths). Explain distinct objectives for historical L1/Ward.D2, sparse graph Ward, observed-entry SSE.

### Page 3: Mathematics — “When does the instrument destroy a symmetry?”

A **large interactive explanatory figure** with four connected views: (i) physically distinct rest-frame spectra; (ii) one bandpass measurement; (iii) spectra after the same Doppler shift; (iv) post-shift predicted photometric fluxes. A miniature classical factorization condition sits alongside the plotted counterexample. Then **what is known**, **what fails**, **what is being investigated**, **how to falsify it**.

Math belongs alongside readable evidence; no full-screen equations, decorative dashboards, or color-filled “key insight” cards.

### Page 4: Scientific gallery — “The data and the question”

Cards use actual result figures and precise labels, e.g., “Spectral regions in a MaNGA barred galaxy”, “What changes when the rest-frame window changes?”, “How missing channels alter admissible merges”, “A velocity gradient after PSF mixing”. Each example leads to source data, reproducible script, figure, assumptions, comparison method and original paper citation.

**Visual system:** carefully controlled palette (graphite/ink, off-white, one teal accent, scientific categorical region palette), serif display only as restrained typographic texture, plain technical sans for plots and text, precise mathematical typesetting, prominent scientific figure captions. Vector export, keyboard-operable interactions, tested at 390 px mobile, consistent regions and WCS across panels. No faux scientific imagery as a proxy for a measured result.

## C. Natural copy: actual replacements

### Homepage

**Title:** One galaxy. Several spectral questions.

**Deck:** A MaNGA cube may show a smooth stellar continuum and sharply localized nebular emission. CAPIVARA groups spaxels according to their measured spectra, then sums the flux within each region for subsequent analysis. The result depends on the wavelengths and representation used in the comparison.

**Small qualifier:** A region is a spectral grouping, not by itself a distinct stellar population or kinematic component.

**Actions:** “See a MaNGA example” · “Read the method” · “Install CAPIVARA”

**Caption:** *MaNGA observation and CAPIVARA spectral regions.* Colours identify regions and carry no ranking. The regions were defined from the specified spectral comparison; their physical properties require separate measurements. (Use this caption only with the verified, matching real-data figure and analysis metadata.)

### Scientific guide

**Title:** Two spaxels can agree for different reasons.

**Opening:** Similar continua do not guarantee similar emission lines. Two identical rest-frame spectra can also appear different because their line-of-sight velocities differ. CAPIVARA lets the analysis specify which spectral differences matter before building the hierarchy.

**Equation placement:** Immediately following an example of the declared representation—one compact formula, one annotation, one diagnostic plot. Follow with “What is lost?” and “When not to use it?” rather than marketing copy.

### Mathematics

**Title:** The shift is defined on the spectrum. Is it defined on the measurement?

**Opening:** Two galaxies can give the same flux through a broadband filter without having the same SED. Redshifting the spectra can separate those fluxes. The filter has removed the information needed to predict the change from its original measurement alone.

**Classical statement:** A linear action U_g descends through A precisely when it preserves ker(A), under the stated domain and boundedness assumptions. Label this a *known factorization criterion* and display the proof/counterexample.

**Research question:** Which cross-line spectro-spatial statistics can be estimated, or sharply bounded, when a spatially varying velocity field is mixed by a wavelength-dependent PSF/LSF? This is a hypothesis requiring a theorem and benchmarks, **not** a feature of current CAPIVARA.

### API reference

**Old-style title:** “Cluster a 2D Representation of a Data Cube.”

**Replacement:** “Group spaxels by their observed spectra.”

**Definition:** “For eligible spaxels, the historical method subtracts each spectrum's median, compares the resulting arrays using Manhattan distance, and applies Ward.D2 hierarchical updates. Region labels summarize spectral similarity under that choice. They do not imply spatial connectivity or physically distinct components.”

**Limits:** “The historical missing-value fill is an algorithmic convention. Use a declared observed-entry representation when channel validity and eligibility need to be modeled explicitly.”

### Editorial rejection examples

Reject “A powerful, innovative framework that unlocks hidden geometric structure.”  
Replace with “The partition changes when the comparison changes. Here is the same cube analyzed using two spectral representations.”

Reject “Our novel symmetry-preserving spectral operator”.  
Replace with “We are investigating which spectral transformations remain defined after instrumental integration. No new operator has yet passed the mathematical and scientific validation gates.”

Reject “Reconstructing the true galaxy structure.”  
Replace with “Grouping measured spectra and assessing how stable those regions are to the stated choices.”

## D. Where genuinely new mathematics could emerge, without misrepresentation

**Already mature prior art:**
- [Steinert et al. (ICML 2025)](https://proceedings.mlr.press/v267/steinert25a.html): efficient equivariant covariance kernels.
- [Arai & Itano (Phys. Rev. E, September 2026)](https://doi.org/10.1103/grfc-4yk9): group-theoretic upper bounds on inverse reconstructability.
- [Ibort et al. (arXiv:2609.25987)](https://arxiv.org/abs/2609.25987): groupoid-equivariant operators on bounded/stratified domains.
- [Sechaud et al. (ICLR 2026)](https://openreview.net/pdf/6632fddde52bfd904d440c44aafe8074e5ad21bd.pdf): equivariant self-supervision from incomplete measurements.
- Existing astronomical spectral correlation functions, velocity-aligned stacking and PSF-aware forward modeling are mandatory baselines.

**New-math target, not yet a contribution:** for instrument maps A_i and a physically restricted set of multi-line fields M, characterize a *computable family of physically covariant quadratic spectro-spatial functionals* Q(F) for which observations identify a nontrivial value or a sharp, statistically calibrated range. Derive when/why wavelength-dependent spatial PSF mixing plus spatially varying Doppler shifts make them non-identifiable, and whether restricted line-template or geometry assumptions admit a fast certification procedure.

The target is only interesting if it yields a new nontrivial theorem or efficient algorithm that the prior works do not already provide. Start with a **two-line, two-component** counterexample: known intrinsic profiles, distinct emissivity maps, controlled velocity field, PSF/LSF and an exact small-scale identified set. The benchmark should include SCF, ROHSA, velocity alignment and forward modeling. If no new informative result survives, do not promote it.

**Integration path:** research documentation → symbolic/analytic proof obligation → isolated numerical benchmark → independent astrophysical validation → experimental API → (separate review) potential stable promotion. No “group equivariance” badge on the homepage until an actual implemented property exists.

## E. Final editorial review checklist

Read every title out loud. It should sound like a researcher explaining a method, not an advertisement. Verify every claimed operation against code; every plotted observation against source/units; every mathematical claim against the strongest literature. Keep paragraphs short and substantive, avoid empty claims, and reserve visual emphasis for results and scientific distinctions—not decoration.
